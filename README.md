## 🚀 What this app does

claude-code-reverse is a Windows app that gives you a local way to use Claude Code Cli in a reverse-engineered form. It is built for people who want a simple desktop or command-line tool that they can download and run from GitHub releases.

Use it to:

- Open Claude Code from your Windows PC
- Work with a local command-line app
- Keep setup simple
- Start fast without extra tools

## 💻 Before you start

Use a Windows PC with:

- Windows 10 or Windows 11
- At least 4 GB of RAM
- 200 MB of free disk space
- A stable internet connection for the download
- Permission to run apps from downloaded files

For the best result, use a standard user account with admin access in case Windows asks for permission.

## 🧰 Common problems

### App does not open

- Check that the file finished downloading
- Make sure you extracted the ZIP folder first
- Try right-clicking the file and choosing Run as administrator
- Move the app file to a simple folder like `Downloads` or `Desktop`

### Windows blocks the file

- Open the file again and choose the option to run it
- Check SmartScreen prompts
- Confirm that you downloaded the file from the release page

### Console closes right away

- Open the app from an existing Command Prompt window if the release notes suggest it
- Look for missing setup steps
- Run the file again and watch for error text before the window closes

### The app does not respond

- Close the window
- Open it again
- Check your internet connection
- Make sure you entered any required token or account data correctly
